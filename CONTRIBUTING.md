# Contributing

Thank you for your interest in contributing to this project.

## Status
This project is considered _feature-complete_ and not under active developement.

However this does not mean this project is abandoned. Bug reports, feedback and small imrpovements are greatly appreciated.

## Project Direction
The project's purpose is in short: creating JSON schema text for the project config of the C3 language by parsing the input of specific commands of c3c. The core directions are:
- Simple and easy to use.
- Light-weight.
- Using as few dependencies as possible.
- Leaving the documentation to be on the repo instead of on the page. The page provides only a usage guide.

Since this is a small project it is built using vanilla HTML, CSS and JavaScript. Please try to use these for any contributions whenever possible.

## Contributions
Small fixes welcome. These include, for example:

- Bug fixes.
- Compatibility updates.
- Accessibility improvements.
- Documentation/code improvements.
- Other minor improvements.

For these you may submit a pull request directly.

For larger changes and new features, please open an issue first to discuss the proposal. However please keep in mind that they are unlikely to be accepted.
## Pull Requests
Please ensure that the pull requests:
- Adhere to the project's direction.
- Focus on a single task.
- Use consistent and readable formatting.
- Does not introduce any unnecessary dependencies.
- Avoid redundant or unnecessary code.
- For styling, uses existing CSS variables (defined in [theme.css](./css/theme.css)) whenever possible.

## Development
The project can be developed locally using any suitable local web server.

No build system or external services are required as of now.

## Questions and Issues
If you encounter a bug or have a question, please open an issue with enough information to understand and constently reproduce the problem.
